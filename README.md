# ApexPlanet Data Analytics Internship

## Task 1: Foundational Setup & Exploratory Data Analysis (EDA)

### Project Title
**E-Commerce Sales Data — Exploratory Data Analysis**

### Objective
The objective of this project is to understand e-commerce sales data, perform data cleaning and preprocessing, generate statistical summaries, create visualizations, and identify useful business insights.

### Dataset
- **Dataset name:** E-Commerce Sales Dataset
- **Dataset type:** Synthetic educational dataset
- **Rows in raw data:** 121, including one duplicate record
- **Rows after cleaning:** 120
- **Format:** CSV
- **Purpose:** Practice data analytics workflow without exposing personal or confidential information

### Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

### Data Cleaning Performed
- Converted `Order_Date` to a date type.
- Converted `Quantity`, `Sales`, and `Profit` to numeric types.
- Filled missing customer names with `Unknown Customer`.
- Filled missing cities with `Unknown City`.
- Filled missing numeric values with the corresponding median.
- Removed duplicate records.
- Saved the cleaned dataset in `data/processed/`.

### Exploratory Data Analysis Performed
- Dataset shape and structure inspection
- Missing-value analysis
- Duplicate-value analysis
- Descriptive statistics
- Category frequency analysis
- Payment-method frequency analysis
- Bar chart
- Sales histogram
- Sales boxplot
- Sales-versus-profit scatter plot
- Correlation heatmap
- Category and city sales summaries

### How to Run the Project

1. Open the project folder in VS Code.
2. Create and activate a Python environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Open `notebooks/task1_eda.ipynb`.
5. Select the correct Python kernel.
6. Run the notebook cells from top to bottom.

You can also run the script:

```bash
python scripts/analysis.py
```
